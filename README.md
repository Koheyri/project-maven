# Project Maven

Пример настройки и работы с Maven-проектом. Демонстрация управления зависимостями, сборкой и структурой Java-проекта.

## Описание проекта

Проект демонстрирует правильную конфигурацию Maven-проекта: управление зависимостями, плагины, профили, сборка. Может использоваться как шаблон для новых проектов.

**Технологический стек:**
- Maven
- Java

## Цель проекта

| Аспект | Описание |
|--------|----------|
| Что решает | Демонстрация правильной конфигурации Maven-проекта: управление зависимостями, плагины, профили, сборка |
| Для кого | Разработчики, изучающие Maven; шаблон для новых проектов |

## Функциональные требования

### User Stories

| ID | Описание | Приоритет |
|----|----------|-----------|
| US-1 | Управление зависимостями через pom.xml для упрощения подключения библиотек | High |
| US-2 | Выполнение стандартных команд сборки для автоматизации процесса | High |
| US-3 | Правильная структура проекта для следования conventions | High |
| US-4 | Использование профилей для управления конфигурацией разных сред | Medium |

### Use Cases

- Управление зависимостями
- Сборка проекта
- Запуск тестов
- Генерация артефактов
